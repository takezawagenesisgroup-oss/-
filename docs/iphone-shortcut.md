# iPhone ショートカットで「Hey Siri、予定登録」

アプリを開かずに、Siri・ロック画面・アクションボタンから音声で予定を登録できます。
解析は Apps Script 側で行うので、ショートカットは「話した文章を送るだけ」です。

## 作り方

「ショートカット」アプリ → 右上の ＋ → 次のアクションを順に追加します。

1. **テキストを音声入力**（Dictate Text）
   - 言語：日本語
   - 聞き取りを停止：一時停止後（話し終えると自動で止まります）
2. **URL**
   - Apps Script のウェブアプリ URL（`https://script.google.com/macros/s/…/exec`）
3. **URL の内容を取得**
   - 方法：**POST**
   - 本文を要求：**JSON**
   - フィールドを追加：
     - `text`（テキスト）… 変数「音声入力されたテキスト」
4. **辞書の値を取得**：キー `ok`
5. **if** 辞書の値 が「1」/ true なら
   - **通知を表示**：「登録しました：」＋ 音声入力されたテキスト
6. **その他**
   - **通知を表示**：「登録に失敗しました」（詳細は手順 3 の結果の `error` を表示すると分かりやすい）

ショートカット名を **「予定登録」** にすると、「Hey Siri、予定登録」で起動します。

## 便利な置き場所

- **アクションボタン**（iPhone 15 Pro 以降）：設定 → アクションボタン → ショートカット →「予定登録」
- **背面タップ**：設定 → アクセシビリティ → タッチ → 背面タップ → ダブルタップ →「予定登録」
- **ホーム画面／ロック画面のウィジェット**

## 注意

- ショートカットは確認画面なしで登録します。間違えたときは Google カレンダーで修正・削除してください。
- 日付が聞き取れなかった場合は「今日」として登録されます。確認しながら入れたい予定は PWA（ホーム画面のアイコン）を使ってください。

## Android の場合

PWA（ホーム画面の「音声予定」アイコン）を使い、⚙ の「アプリを開いたらすぐ聞き取りを始める」と「確認せずにすぐ登録する」をオンにすると、アイコンのタップ → 話すだけで登録できます。
「HTTP Shortcuts」などのアプリを使えば、iPhone と同様に音声入力の結果を Apps Script に直接送ることもできます（本文 `{"text":"…"}` を POST）。
