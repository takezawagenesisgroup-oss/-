# はじめかた（竹澤さん用・約 20 分）

スマホのホーム画面に「音声予定」アプリを置いて、**タップ → 話す → 竹澤さんの Google カレンダーに登録** できるようにする手順です。
使う Google アカウントは **takezawa@genesis-group-official.com** です。

## 0. Google アカウントの準備（初回のみ・3 分）

1. スマホの「Google カレンダー」アプリを開き、右上のアイコン →「別のアカウントを追加」→ `takezawa@genesis-group-official.com` でログイン。
   初回は新しいパスワードの設定を求められます。
2. 以降、このアカウントのカレンダーを見るようにします（他のアカウントのカレンダーは、左上メニューでチェックを外すと非表示にできます）。

## 1. 登録用のプログラム（Apps Script）を作る（PC で・10 分）

PC のブラウザで `takezawa@genesis-group-official.com` にログインした状態で行います。

1. <https://script.google.com/> を開き、左上「新しいプロジェクト」。
2. 左上の「無題のプロジェクト」をクリックして、名前を **音声スケジュール** に変更。
3. 左の ⚙「プロジェクトの設定」→「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェック。
4. 左の「<>」（エディタ）に戻り、ファイル一覧の **appsscript.json** を開いて中身をすべて消し、
   [gas/appsscript.json](../gas/appsscript.json) の中身を貼り付け。
5. ファイル一覧の **コード.gs** を開いて中身をすべて消し、
   [gas/AllInOne.gs](../gas/AllInOne.gs) の中身を貼り付け（GitHub の画面右上の「コピー」ボタンで全部コピーできます）。
6. 💾（保存）を押す。
7. 上部の関数の選択欄で **setup** を選び「実行」。
   - 「承認が必要です」→「権限を確認」→ アカウントを選ぶ →「許可」。
   - 「このアプリは Google で確認されていません」と出たら「詳細」→「音声スケジュール（安全ではないページ）に移動」→「許可」。
   - 下の実行ログに「登録先カレンダー: …」と出れば OK。
8. 右上「デプロイ」→「新しいデプロイ」→ 左の ⚙ で「ウェブアプリ」を選ぶ。
   - 次のユーザーとして実行：**自分（takezawa@genesis-group-official.com）**
   - アクセスできるユーザー：**全員**
   - 「デプロイ」→ 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピー。

> 「アクセスできるユーザー」に「全員」が出ない場合：会社の Workspace の設定で外部公開が制限されています。
> 管理コンソール →「アプリ」→「Google Workspace」→「ドライブとドキュメント」→「共有設定」で、組織外との共有を許可してください。
>
> この URL を知っている人は予定を登録できるので、他の人には教えないでください。

## 2. スマホのホーム画面にアプリを置く（3 分）

1. スマホの **Safari**（Android は Chrome）で、次のアドレスを開く。`<ウェブアプリのURL>` の部分は 1-8 でコピーした URL に置き換えます。
   ```
   https://takezawagenesisgroup-oss.github.io/-/voice/?gas=<ウェブアプリのURL>
   ```
   ※ 長いので、PC から自分宛てにメールや LINE で送って、スマホで開くと楽です。
2. 画面上部に「登録先: Apps Script のカレンダー」と出ていれば設定完了。
3. 共有ボタン（□↑）→「**ホーム画面に追加**」→「追加」。ホーム画面に「音声予定」アイコンができます。

## 3. 使ってみる

1. ホーム画面の「音声予定」をタップ → 青いマイクボタンをタップ（初回はマイクの許可を「許可」）。
2. 「**明日の午後3時から1時間、田中さんと打ち合わせ、場所は渋谷オフィス**」のように話す。
3. 確認画面で内容を確かめて「登録する」→ Google カレンダーに入ります。

**もっと手早く**：⚙ →「確認せずにすぐ登録する」をオンにすると、日付と時刻が聞き取れたときは話し終えた瞬間に登録されます。

**Siri からも使う（任意）**：「Hey Siri、予定登録」→ 話すだけで登録。作り方は [iphone-shortcut.md](iphone-shortcut.md)。

## うまくいかないとき

| 症状 | 対処 |
| --- | --- |
| 「登録に失敗しました」 | ⚙ →「接続テスト」。だめなら手順 1-8 の「アクセスできるユーザー：全員」を確認 |
| マイクボタンを押しても反応しない | iPhone の「設定」→「Safari」→「マイク」を「確認」または「許可」に |
| 違う日付・時刻になる | 確認画面で直してから「登録する」。午前／午後を言うと確実です（「3時」だけだと 15 時とみなします） |
| プログラムを更新したい | Apps Script の「デプロイ」→「デプロイを管理」→ ✏️ →「バージョン：新バージョン」→「デプロイ」（URL は変わりません） |
