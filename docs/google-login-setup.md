# Google ログイン（複数人で使う）の設定

この設定を 1 回行うと、**誰でも自分の Google アカウントでログインするだけで、自分の Google カレンダーに音声で予定を登録** できるようになります。
利用者ごとの Apps Script の準備は不要です。

管理者が行う作業は「Google Cloud で OAuth クライアント ID を作り、`web/config.js` に書く」だけです（約 15 分）。

## 1. Google Cloud プロジェクトを作る

1. <https://console.cloud.google.com/> を開き、上部のプロジェクト選択 →「新しいプロジェクト」（名前：`voice-schedule` など）。
2. 「API とサービス」→「ライブラリ」→ **Google Calendar API** を検索して「有効にする」。

## 2. OAuth 同意画面（Google Auth Platform）を設定する

「API とサービス」→「OAuth 同意画面」（または「Google Auth Platform」）→「開始」。

- アプリ名：`音声スケジュール`
- サポートメール：管理者のメールアドレス
- **対象（ユーザーの種類）**
  - 会社で **Google Workspace** を使っていて、社員のアカウントだけで使う場合 → **内部**（審査不要・人数制限なし）
  - Gmail（@gmail.com）のアカウントで使う場合 → **外部**
- 連絡先メールアドレスを入力して作成。

**「外部」を選んだ場合**
- 「対象」→「テストユーザー」に、使う人の Gmail アドレスを追加します（最大 100 人）。
  追加した人だけがログインできます。
- ログイン時に「Google はこのアプリを確認していません」と表示されます。「続行」で進めて問題ありません（自社で作ったアプリのため）。
- 100 人を超える／不特定の人に使ってもらう場合は、「アプリを公開」して Google の審査（カレンダー権限のため必要）を受けます。

「データアクセス」→「スコープを追加」で次を追加しておきます（任意ですが同意画面の表示が分かりやすくなります）。
- `.../auth/calendar.events`（予定の表示と編集）

## 3. OAuth クライアント ID を作る

「API とサービス」→「認証情報」（または「クライアント」）→「クライアントを作成」/「認証情報を作成」→「OAuth クライアント ID」

- アプリケーションの種類：**ウェブ アプリケーション**
- 名前：`音声スケジュール`
- **承認済みの JavaScript 生成元** に追加：
  - `https://takezawagenesisgroup-oss.github.io`（GitHub Pages で公開する場合。別の場所で公開する場合はその URL の「https://ドメイン」部分）
  - `http://localhost:8080`（開発用・任意）
- リダイレクト URI は不要です。

作成すると **クライアント ID**（`xxxxxxxx.apps.googleusercontent.com`）が表示されます。
クライアント ID は公開されても問題ない値です（「クライアント シークレット」は使いません）。

## 4. アプリに設定する

`web/config.js` の `googleClientId` にクライアント ID を書いて main に反映します。

```js
window.VOICE_SCHEDULE_CONFIG = {
  googleClientId: 'xxxxxxxx.apps.googleusercontent.com'
};
```

## 利用者の使い方

1. スマホで公開 URL（`https://takezawagenesisgroup-oss.github.io/-/`）を開き、ホーム画面に追加。
2. 画面上部の「Google でログイン」→ 自分のアカウントを選び、カレンダーへのアクセスを「許可」。
3. マイクをタップして話す →「登録する」→ **ログインした人の Google カレンダー** に登録されます。

- 画面上部に「登録先: ○○@gmail.com」と表示されるので、どのカレンダーに入るか確認できます。
- 別のアカウントに切り替えるときは「切替」（または ⚙ →「アカウント切替」）。
- ログインの有効期限は約 1 時間です。切れていると「登録する」を押したときに Google の確認画面が一瞬表示されます（2 回目以降はタップ不要で自動で閉じます）。
  そのため、期限切れのときは「確認せずにすぐ登録する」設定でも確認画面で止まります。

## 2 つの登録方法の違い

| | Google ログイン（このページ） | Apps Script 経由 |
| --- | --- | --- |
| 使える人 | 誰でも（自分のアカウントでログイン） | Apps Script を作った本人 |
| 登録先 | ログインした人のカレンダー | Apps Script を作った人のカレンダー |
| 準備 | 管理者が 1 回だけ OAuth クライアント ID を作る | 利用者ごとに Apps Script を作る |
| Siri / ショートカット | 使えない | 使える |
| ログイン期限 | 約 1 時間ごとに再確認（自動） | なし |

両方を併用することもできます（⚙ の「登録方法」で切り替え）。
