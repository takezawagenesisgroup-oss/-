# 音声スケジュール登録（Google カレンダー）

スマホのホーム画面のアイコンを **ワンタップ → 話すだけ** で、Google カレンダーに予定を登録する仕組みです。
iPhone なら「Hey Siri、予定登録」でも使えます。

**複数人で使えます。** 各自が自分の Google アカウントでログインすれば、それぞれ自分の Google カレンダーに登録されます（アカウントの切り替えも画面上で可能）。

> 「10月15日14時から16時まで本社会議室で営業会議」
> → 10/15 14:00〜16:00「営業会議」（場所：本社会議室）として Google カレンダーに登録

将来は、Google カレンダーの予定を自社グループウェア **ジェネシスワークシステム** のスケジュールへ自動連携します（準備済み・後述）。

## 全体の構成

登録方法は 2 種類あり、⚙ の「登録方法」で切り替えられます。

| | **Google ログイン**（複数人向け・おすすめ） | **Apps Script 経由**（個人向け） |
| --- | --- | --- |
| 登録先 | ログインした人の Google カレンダー | Apps Script を作った人のカレンダー |
| 準備 | 管理者が 1 回だけ設定 → [docs/google-login-setup.md](docs/google-login-setup.md) | 利用者ごとに Apps Script を作る（下記） |
| Siri / ショートカット | 使えない | 使える |

```
【Google ログイン】
 スマホ ──話す──▶ 音声スケジュール (PWA) ──Google でログイン──▶ ログインした人の Google カレンダー

【Apps Script 経由】
 ┌────────────┐  話す   ┌──────────────────────┐  POST  ┌───────────────────┐       ┌──────────────────┐
 │ スマホ      │ ──────▶ │ 音声スケジュール (PWA) │ ─────▶ │ Google Apps Script │ ────▶ │ Google カレンダー │
 │ ホーム画面  │         │ 音声認識・解析・確認   │        │ （自分の権限で登録） │       │  （正）           │
 └────────────┘         └──────────────────────┘        └───────────────────┘       └────────┬─────────┘
 ┌────────────┐  話す                                          ▲                                │ 変更を検知
 │ Siri       │ ─── iPhone ショートカット ─────────────────────┘                                ▼
 └────────────┘                                                                      ┌──────────────────────────┐
                                                                                     │ ジェネシスワークシステム   │
                                                                                     │ （カレンダー完成後に連携） │
                                                                                     └──────────────────────────┘
```

- **Google カレンダーを「正（マスター）」** にします。音声で入れた予定も、Google カレンダーに直接手入力した予定も、すべて同じ経路でジェネシスワークシステムへ流れます。
- **Google ログイン** では、画面から Google Calendar API を直接呼び、ログインした本人のカレンダーに登録します（サーバー不要）。
- **Apps Script 経由** では、Google Apps Script（GAS）が作成者のアカウントとして登録するため、ログインの期限切れがなく Siri からも使えます。

| フォルダ | 内容 |
| --- | --- |
| `web/` | スマホで使う画面（PWA）。音声認識 → 内容の読み取り → 確認 → 登録 |
| `web/config.js` | 管理者が設定する値（Google ログイン用の OAuth クライアント ID） |
| `web/google-calendar.js` | Google ログインと Calendar API への登録 |
| `gas/` | Google Apps Script。予定の登録 API と、ジェネシスワークシステム連携（準備中） |
| `web/parser.js` | 日本語の日時・場所・内容を読み取る処理（`gas/Parser.js` は同じもののコピー） |
| `docs/` | Google ログインの設定、iPhone ショートカットの作り方、ジェネシスワークシステム連携の設計 |

## 話し方の例

| 話した内容 | 登録される予定 |
| --- | --- |
| 10月15日14時から16時まで本社会議室で営業会議 | 10/15 14:00〜16:00 営業会議（本社会議室） |
| 明日の午後3時から1時間、田中さんと打ち合わせ、場所は渋谷オフィス | 明日 15:00〜16:00 田中さんと打ち合わせ（渋谷オフィス） |
| 来週月曜10時から12時まで新宿で取引先と商談 | 来週月曜 10:00〜12:00 取引先と商談（新宿） |
| 今週金曜3時から5時 役員会議 | 今週金曜 15:00〜17:00 役員会議 |
| 10月20日から22日まで大阪出張 | 10/20〜10/22 終日 大阪出張 |
| 25日の夜7時から懇親会、場所は新橋の居酒屋 | 25日 19:00〜20:00 懇親会（新橋の居酒屋） |

読み取りのルール：
- **日付**：「10月15日」「15日」「今日／明日／明後日」「来週月曜」「金曜」など。過ぎた日付は翌月・翌年とみなします。
- **時刻**：「14時」「14時半」「午後2時」「14:30」「正午」。午前／午後を言わない 1〜7 時は **午後** とみなします（例：「3時」→15時）。
- **終了**：「〜時まで」「1時間」「30分」。言わなければ 1 時間の予定になります。「終日」で終日予定。
- **場所**：「場所は〇〇」「〇〇で」「〇〇にて」「@〇〇」。
- 読み取れなかった項目は確認画面で注意が表示されるので、その場で直せます。

## セットアップ

- **複数人で使う（Google ログイン）**：管理者が [docs/google-login-setup.md](docs/google-login-setup.md) の設定を 1 回行い、下の「2. 画面（PWA）を公開する」を行えば、あとは各自がアプリを開いて「Google でログイン」するだけです。
- **自分だけ・Siri から使う（Apps Script 経由）**：以下の 1〜4 を行います（約 15 分）。

### 1. Google Apps Script を用意する（Apps Script 経由の場合）

1. 予定を登録したい Google アカウントで <https://script.google.com/> を開き、「新しいプロジェクト」を作成（名前は「音声スケジュール」など）。
2. 左の ⚙「プロジェクトの設定」→「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェック。
3. エディタに次の 4 ファイルを作り、このリポジトリの `gas/` の中身をそれぞれ貼り付けて保存。
   - `appsscript.json`（既存の内容を置き換え）
   - `Code.gs` ← `gas/Code.js`（既存の内容を置き換え）
   - `Parser.gs` ← `gas/Parser.js`
   - `GenesisSync.gs` ← `gas/GenesisSync.js`
4. 上部の関数選択で **`setup`** を選んで「実行」。権限の確認が出たら許可します
   （「このアプリは Google で確認されていません」と出た場合は「詳細」→「（安全ではないページ）に移動」）。
5. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 「デプロイ」を押し、表示される **ウェブアプリ URL**（`https://script.google.com/macros/s/…/exec`）を控えます。

> 現在は合言葉（API キー）なしで動く設定です。**ウェブアプリ URL を知っている人は誰でも予定を登録できる** ため、URL は他人に共有しないでください（必要になったら認証を追加できます）。
> 登録先を会社用など別のカレンダーにしたい場合は、スクリプトプロパティ `CALENDAR_ID` にカレンダー ID を設定します（Google カレンダーの「設定と共有」→「カレンダーの統合」に記載）。

> **コードを更新したとき**は「デプロイ」→「デプロイを管理」→ 鉛筆アイコン →「バージョン：新バージョン」で更新すると URL が変わりません。

### 2. 画面（PWA）を公開する

`web/` フォルダを HTTPS で公開します（マイクを使うため HTTPS が必須です）。

- **GitHub Pages**（このリポジトリに設定済み）：GitHub の Settings → Pages → Source を「GitHub Actions」にすると、`main` に push するたびに自動公開されます。
  公開 URL：`https://<ユーザー名>.github.io/<リポジトリ名>/`
  ※ 非公開リポジトリで Pages を使うには GitHub の有料プランが必要です。使えない場合は Netlify / Cloudflare Pages / Firebase Hosting などに `web/` をそのままアップロードしても動きます。
- 画面のファイルには Apps Script の URL は含まれません（URL は各端末に保存されます）。

### 3. スマホに入れる

1. スマホで次の URL を開くと、設定が自動で取り込まれます（URL は控えた値に置き換え）。
   ```
   https://<公開URL>/?gas=<ウェブアプリURL>
   ```
   ※ 手入力したい場合は画面右上の ⚙ から入力し、「接続テスト」で確認できます。
2. ホーム画面に追加する
   - **iPhone（Safari）**：共有ボタン →「ホーム画面に追加」
   - **Android（Chrome）**：︙ メニュー →「ホーム画面に追加」または「アプリをインストール」
3. ホーム画面の「音声予定」アイコンをタップ → マイクボタンをタップ → 話す → 「登録する」。

**さらに手間を減らす設定**（⚙ から）
- 「確認せずにすぐ登録する」：日付と時刻がはっきり読み取れたときは、話し終えた瞬間に登録します。
- 「アプリを開いたらすぐ聞き取りを始める」：Android の Chrome などでは、アイコンを押すだけで聞き取りが始まります（iPhone はブラウザの制限でマイクボタンのタップが必要）。

### 4. iPhone なら Siri からも（おすすめ）

アプリを開かず「Hey Siri、予定登録」→ 話すだけで登録できます。作り方は [docs/iphone-shortcut.md](docs/iphone-shortcut.md)。

## ジェネシスワークシステムとの連携（準備済み）

ジェネシスワークシステムのカレンダー機能が完成したら、`gas/GenesisSync.js` を有効にするだけで、
**Google カレンダーの追加・変更・削除がジェネシスワークシステムのスケジュールに自動反映** されます。
音声で登録した予定だけでなく、Google カレンダーに直接入力した予定も連携されます。

ジェネシスワークシステム側で用意してほしい受け口（API）の仕様は [docs/genesis-integration.md](docs/genesis-integration.md) にまとめています。

## 開発者向け

```sh
npm test                 # 日本語解析のテスト
./scripts/sync-gas.sh    # web/parser.js を変更したら gas/Parser.js にコピー（テストで一致を確認しています）
```

ローカルで画面を確認する場合は `npx serve web` などで `web/` を配信し、`http://localhost` で開きます（localhost ならマイクも使えます）。
