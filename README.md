# 設備・備品管理ツール（サービスメンテナンス部）

パチンコ店・マンション・戸建て・空き地・倉庫・本社などの保有施設を対象に、
工具・備品・車両の管理と、作業実績（写真・音声メモ）の蓄積を行うための
社内向けWebアプリです。年配の方でも使えるよう、アイコン中心・大きな文字の
シンプルな画面構成にしています。

## 主な機能

- **ホーム**：検索／登録／施設一覧の3つの大きなボタンから開始
- **検索**：施設・トラブル内容をアイコンで選ぶと、過去の実績から必要な
  道具・車両を「①手前・②中・③奥」の3段階（または使用頻度3段階）に
  分けてリスト表示
- **登録**：施設→作業内容→（任意で類似作業へ関連付け）→写真撮影→
  音声入力→道具/車両チェック→日付・担当者・作業時間、の順に進む
  ステップ形式。音声入力はブラウザの音声認識（Web Speech API）を使い、
  話した内容からマスタに登録済みの道具名・車両名を自動検出してチェックします
- **施設一覧／施設詳細**：施設ごとに過去の作業をツリー表示（類似作業を
  親子関係で追加登録できます）
- **記録の修正**：登録済みの内容はいつでも編集可能
- **一般知見（参考ガイド）**：社内の実績記録がまだない施設×トラブルの
  組み合わせでも、帯広市・音更町の気候（積雪・凍害等）を踏まえた一般的な
  対処法・必要な道具・車両・目安時間を検索結果に表示。実績が蓄積されたら
  そちらが優先されます（下記「一般知見の情報源について」参照）
- **管理画面（管理者のみ）**：道具・備品マスタ（カテゴリー・3段階・保管場所）、
  車両マスタ、一般知見（参考ガイド）、利用者アカウントの管理

## 保管ルールの考え方

- 工具（カテゴリー別）：① 手前＝よく使う手持ち工具／② 中＝よく使う備品・
  専用工具／③ 奥＝大型工具・大型品
- その他備品（使用頻度別）：① 手前＝よく使う／② 中＝そこそこ使う／
  ③ 奥＝めったに使わない

## データの持ち方

- **データベース**：PostgreSQL（`POSTGRES_URL` 環境変数で接続）
- **写真**：`BLOB_READ_WRITE_TOKEN` が設定されていればVercel Blobに保存、
  未設定ならローカルの `public/uploads/` に保存（ローカル動作確認用）

初回アクセス時にテーブル作成と初期データ投入（初期アカウント・保有施設13件・
工具備品マスタ・車両マスタ・トラブル種別・デモ用作業実績5件・一般知見26件）
が自動で行われます。

- 初期アカウント：`admin` / `admin1234`（管理者）、`sato` `suzuki` `takahashi`
  / `staff1234`（担当者）※本番運用前に必ずパスワードを変更してください

## 使い方（ローカルでの開発・試用）

PostgreSQLが必要です（Dockerや、お使いのPCに入れたPostgresで構いません）。

```bash
# 1. .env.local を作成（.env.example を参考に）
cp .env.example .env.local
# POSTGRES_URL に自分のPostgres接続文字列を、SESSION_SECRETに適当な文字列を入れる

# 2. 依存関係インストール・起動
npm install
npm run dev
# http://localhost:3000 を開く
```

## Vercelへのデプロイ手順

1. **GitHubのリポジトリをVercelにインポート**
   - https://vercel.com/new を開き、このリポジトリ（`claude/facility-tool-management-7uo72h`
     ブランチ、または統合後のmainブランチ）を選択してインポート
2. **データベースを作成**
   - プロジェクト作成後、プロジェクト画面の「Storage」タブ → 「Create Database」
     → 「Postgres」を選択して作成し、プロジェクトに接続（Connect）
   - これで `POSTGRES_URL` などの環境変数が自動で設定されます
3. **写真保存用のBlobストレージを作成**
   - 同じく「Storage」タブ → 「Create Database」→「Blob」を選択して作成し、
     プロジェクトに接続
   - `BLOB_READ_WRITE_TOKEN` が自動で設定されます
4. **SESSION_SECRETを設定**
   - プロジェクトの「Settings」→「Environment Variables」で `SESSION_SECRET`
     にランダムな文字列（`openssl rand -base64 32` などで生成）を追加
5. **再デプロイ**
   - 環境変数を追加した後、「Deployments」タブから最新デプロイを
     「Redeploy」して環境変数を反映
6. 発行されたURL（例：`https://xxxx.vercel.app`）にアクセスし、初期アカウントで
   ログインして動作確認

以降、このリポジトリのブランチに変更をpushすると自動的に再デプロイされます。

## 一般知見の情報源について

初期データに含まれる26件の「一般知見（参考ガイド）」は、社内の実績が
まだない状態でも検索機能が使えるように用意した**一般的な参考情報**であり、
御社の実際の作業実績ではありません。以下の一般的な知見をもとに作成しています。

- 寒地土木研究所（土木研究所）等の資料による、寒冷地アスファルト舗装の
  凍上・凍害と補修の一般的な考え方
- マンション等の屋根雪庇・つらら（氷柱）除去に関する一般的な注意点
  （転落・落雪事故のリスク、管理組合の保険確認など）
- 積雪地域での水道管凍結・破裂時の一般的な応急対応方法
- 空き地の雑草放置に関する自治体条例は全国的に多くの自治体で制定されて
  いる一般的な傾向（**帯広市・音更町の条例の正確な内容・基準回数は確認
  できていないため、実際の頻度・基準は各自治体の窓口で確認することを
  推奨**とガイド内に注記しています）

実際の作業実績が「登録」から蓄積されていくと、検索結果はこの一般知見より
実績データを優先して表示するようになります。内容の追加・修正・削除は
「管理」→「📖 参考ガイド」から行えます。

## 現時点の制約・今後の検討事項

- **検索は「画像から自動判定」ではなく「トラブルの種類（アイコン選択）から
  過去実績を集計」する方式です。** 写真の添付欄はありますが、現状は
  画像そのものを解析して道具を判定する機能（画像AI）は実装していません。
  今後、画像認識APIと連携すれば「写真を撮ると候補が絞り込まれる」動きに
  拡張できます。
- 音声入力の道具自動検出は、話した文章にマスタ登録済みの名称がそのまま
  含まれているかで判定する簡易的な仕組みです。方言や言い回しの揺れには
  完全対応していないため、確認画面で必ずタップして最終確認してください。
- 音声入力（Web Speech API）はChrome系ブラウザでの動作を想定しています。
  対応していないブラウザでは手入力に切り替わります。
- データベースはPostgreSQLで、最大20名程度の利用規模を想定した接続数
  （最大5コネクション）で構成しています。利用者・データ量が大きく増える
  場合は接続プールの見直しを推奨します。
