# 株価チェッカー

銘柄コードを入力すると最新の株価と値動きを確認できるシンプルなアプリです。

## 構成

- バックエンド: Node.js + Express（`server.js`）
  - 外部の株価データ（Yahoo Finance の公開チャートAPI、APIキー不要）をサーバー側で取得し、フロントに中継します
- フロントエンド: ビルド不要のプレーンな HTML / CSS / JS（`public/`)

## セットアップ

```bash
npm install
npm start
```

起動後、ブラウザで http://localhost:3000 を開いてください。

## 使い方

- 検索欄に銘柄コードを入力します
  - 米国株の例: `AAPL`, `MSFT`, `GOOGL`
  - 日本株の例: `7203.T`（トヨタ自動車）, `9984.T`（ソフトバンクグループ）, `6758.T`（ソニーグループ）
- 現在値・前日比・過去の値動きグラフが表示されます
- グラフは 5日 / 1ヶ月 / 6ヶ月 / 1年 の期間で切り替えられます
