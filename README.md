# 設備・備品管理ツール（サービスメンテナンス部）

パチンコ店・マンション・戸建て・空き地・倉庫・本社などの保有施設を対象に、
工具・備品・車両の管理と、作業実績（写真・音声メモ）の蓄積を行うための
社内向けWebアプリです。年配の方でも使えるよう、アイコン中心・大きな文字の
シンプルな画面構成にしています。

## 主な機能

- **ホーム**：検索／登録／施設一覧の3つの大きなボタンから開始
- **検索**：施設・トラブル内容をアイコンで選ぶと、過去の実績から必要な
  道具・車両を「①手前・②中・③奥」の3段階（または使用頻度3段階）に
  分けてリスト表示
- **登録**：施設→作業内容→（任意で類似作業へ関連付け）→写真撮影→
  音声入力→道具/車両チェック→日付・担当者・作業時間、の順に進む
  ステップ形式。音声入力はブラウザの音声認識（Web Speech API）を使い、
  話した内容からマスタに登録済みの道具名・車両名を自動検出してチェックします
- **施設一覧／施設詳細**：施設ごとに過去の作業をツリー表示（類似作業を
  親子関係で追加登録できます）
- **記録の修正**：登録済みの内容はいつでも編集可能
- **管理画面（管理者のみ）**：道具・備品マスタ（カテゴリー・3段階・保管場所）、
  車両マスタ、利用者アカウントの管理

## 保管ルールの考え方

- 工具（カテゴリー別）：① 手前＝よく使う手持ち工具／② 中＝よく使う備品・
  専用工具／③ 奥＝大型工具・大型品
- その他備品（使用頻度別）：① 手前＝よく使う／② 中＝そこそこ使う／
  ③ 奥＝めったに使わない

## 使い方（開発・試用）

```bash
npm install
npm run dev
# http://localhost:3000 を開く
```

初回アクセス時にデータベース（`data/app.db`、SQLite）が自動作成され、
以下の初期データが登録されます。

- 初期アカウント：`admin` / `admin1234`（管理者）、`sato` `suzuki` `takahashi`
  / `staff1234`（担当者）※本番運用前に必ずパスワードを変更してください
- 保有施設13件（パチンコ3・マンション3・戸建て2・空き地2・倉庫2・本社1）
- 工具・備品マスタ（大工道具／配管・水道／電気工事／外壁・屋根／
  舗装・アスファルト補修／除雪・雪害対応／草刈り・造園／消耗品・電球／清掃用品）
- 車両マスタ（高所作業車／2トン車／4トン車／軽バン／ハイエース／
  軽トラック／除雪車×2）
- トラブル種別（舗装補修・屋根・外壁・水道・電気・除雪・雪害・草刈り・
  害獣・清掃・その他）
- デモ用の作業実績5件（検索・ツリー表示の動作確認用）

本番公開する場合は `SESSION_SECRET` 環境変数にランダムな文字列を設定してください。

## 現時点の制約・今後の検討事項

- **検索は「画像から自動判定」ではなく「トラブルの種類（アイコン選択）から
  過去実績を集計」する方式です。** 写真の添付欄はありますが、現状は
  画像そのものを解析して道具を判定する機能（画像AI）は実装していません。
  今後、画像認識APIと連携すれば「写真を撮ると候補が絞り込まれる」動きに
  拡張できます。
- 音声入力の道具自動検出は、話した文章にマスタ登録済みの名称がそのまま
  含まれているかで判定する簡易的な仕組みです。方言や言い回しの揺れには
  完全対応していないため、確認画面で必ずタップして最終確認してください。
- 音声入力（Web Speech API）はChrome系ブラウザでの動作を想定しています。
  対応していないブラウザでは手入力に切り替わります。
- データベースはSQLite（ファイル1つ）で管理しており、最大20名程度の
  利用規模を想定した構成です。利用者・データ量が大きく増える場合は
  DBの見直しを推奨します。
