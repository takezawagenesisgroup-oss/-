# サウンド素材について

このディレクトリの `.wav` は `scripts/generate-sounds.js` による**プロシージャル生成音**(ノイズ整形+トーン合成)です。録音物ではないため著作権上のクリアランスは不要です(凪と同じ方式)。

- `breath_loop.wav`: 呼吸に見立てたスウェル(約4.8秒周期)のループ。常時低音量で流し、「隣に誰かがいる気配」の土台にする
- `sigh.wav` / `stretch.wav` / `hum.wav` / `page_turn.wav`: ランダムなタイミングで時々挟む「生活音」のワンショット(ため息・伸び/衣擦れ・鼻歌・ページをめくる音)

再生成したい場合は `node scripts/generate-sounds.js` を実行してください(`assets/sounds/*.wav` を上書きします)。品質を上げたい場合は、著作権フリー/ライセンス取得済みの実録音への差し替えを検討してください。
