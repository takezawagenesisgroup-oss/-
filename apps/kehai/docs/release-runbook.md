# リリース手順書(人間がやる作業)

実装・ブランド素材・ストア文言はここまでの作業で用意済み。ここから先はApple/Googleの開発者アカウントを持つ人間でないと進められない作業をフェーズ別にまとめた。位置情報を扱わない点で凪に近い構成(隣より単純)。3アプリ共通のPhase 1・2(開発者アカウント登録・EAS Build準備)は、いずれかのアプリで既に済ませていれば共用できる。

## 概要

| 項目 | 目安 |
|---|---|
| 初期費用 | 約¥19,000(Apple $99/年 + Google $25一度きり、3アプリで共用可) |
| 登録〜審査提出までの期間 | 3〜10日 |
| Macの要否 | **不要** — EAS Buildでクラウドビルド可能 |

## Phase 1〜2. 開発者アカウント登録・EAS Buildの準備

凪の `docs/release-runbook.md` のPhase 1・2と同一。共用できる。

## Phase 3. アプリ内課金商品の作成

💰 無料(手数料はストア側の標準率) / ⏱ 1〜2時間+実装差し替え

- [ ] App Store Connect で非消耗型商品を作成。Product ID例: `unlock_all_voices`
- [ ] Google Play Console で管理対象アプリ内アイテムを作成(同じProduct IDで揃える)
- [ ] `react-native-iap` を導入し、`app/purchases.ts` を差し替え(手順はファイル冒頭のコメントに記載、凪・隣と同じパターン)

## Phase 4. 音声・キャラクター表現の最終確認

💰 ¥0(端末TTSのまま)〜 / ⏱ 半日

- [ ] 4口調の台詞(`app/personas.ts`)を実機で読み上げさせ、不自然な間や誤読が無いか確認
- [ ] キャラクタービジュアル(イラスト)を追加する場合、Bing Image Creator / SeaArt等で生成した画像の**商用利用可否をその時点の利用規約で再確認**してから組み込む
- [ ] お子様も利用しうる想定であれば、口調の内容が応援・気遣いの範囲に収まっているか改めて読み返す(恋愛的・扇情的表現が入っていないか)

## Phase 5. 法務ページの仕上げ

💰 ¥0 / ⏱ 15分

- [ ] `docs/legal/privacy-support.html` のお問い合わせ先を実際のメールアドレスに差し替え
- [ ] ページを公開してURLを取得(アーティファクトの共有設定を「公開」に、または自前ドメインでホスティング)
- [ ] 取得したURLを両ストアの「プライバシーポリシーURL」「サポートURL」欄に設定

## Phase 6. ストア掲載情報の入力

💰 ¥0 / ⏱ 1〜2時間

- [ ] `docs/store-listing.md` の文言をコピペ
- [ ] スクリーンショットを撮影(5枚構成)
- [ ] App Privacyアンケートは全項目「収集しない」で回答可能(凪と同じ)

## Phase 7. 実機テスト・審査提出

💰 ¥0 / ⏱ 審査は1〜3日

- [ ] EAS Buildで本番用ビルドを作成しTestFlight / 内部テストへ配信
  ```bash
  eas build --platform ios --profile production
  eas submit --platform ios
  ```
- [ ] 実機で全機能を確認: 4口調 × 声の高さ3段階、時間選択(5分/30分/1時間/2時間)、ランダムな声かけ・生活音、音楽再生中のダッキング、購入フロー・復元
- [ ] 問題なければ審査へ提出

## Phase 8. 公開・ローンチ告知

💰 ¥0 / ⏱ 公開当日〜1週間

- [ ] 審査通過後、公開日時を設定
- [ ] `docs/launch-copy.md` の `[App Store link]` 等を実URLに差し替えて投稿
- [ ] 初動のレビュー・問い合わせに目を配る
