# 気配 -Kehai-

勉強中・作業中・就寝前など、時間を決めるだけで「隣に誰かがいる気配」を感じられる汎用の伴侶アプリ。呼吸の音を土台に、時々応援や気遣いの声をかけたり、伸び・ため息・鼻歌などの生活音がランダムに挟まる。Expo (React Native) 製。

凪・隣と同じ「凡庸なサブスクではなく、買い切りの廉価版」路線。TTSで台詞を動的生成するため、声優ライセンス費用ゼロで買い切り¥480の複数口調を提供する。

## キャラクター設計について

「ギャル/清楚/若い子/熟女」という要望は、**口調のスタイル**として表現した(清楚系・ギャル系・後輩系・お姉さん系の4種)。内容は全て応援・気遣いで統一しており、恋愛的・扇情的な表現は含めていない。ビジュアルはリアルなイラストではなく、抽象的なアイコンマーク(暖色の光を柔らかい弧が包み込むデザイン)で表現している。イラストレーターへの発注やAI画像生成サービスとの連携は本セッションの対応範囲外。

## セットアップ

```bash
npm install
npm run web      # ブラウザで動作確認。「お試し5分」で短時間に一通り体験できる
npm run ios      # 要 macOS + Xcode(または凪・隣と同様にEAS Buildでも可)
npm run android
```

## 仕組み

```
App.tsx                      エントリーポイント。口調/声の高さ/時間の選択、実行中・終了画面
app/
  theme.ts                   配色トークン(暖かく静かなランプの灯りをイメージ)
  personas.ts                 口調(清楚系/ギャル系/後輩系/お姉さん系)ごとの台詞バンク
  usePresenceSession.ts        時間(5分/30分/1時間/2時間)のカウントダウンと、ランダムな
                                間隔での声かけトリガー(応援60%/気遣い40%)を管理
  useVoiceCompanion.ts          トリガーを受けて台詞を選び、expo-speechで読み上げる。
                                直前と同じ台詞は選ばれない
  useAmbientPresence.ts         常時流れる呼吸ループと、ランダムな間隔で挟む生活音
                                (ため息・伸び・鼻歌・ページをめくる音)を管理
  purchases.ts                  買い切り解放の状態管理(凪・隣と同じAsyncStorageスタブ実装)
  components/
    PersonaPicker.tsx           口調選択カード(ロック中は🔒)
    PaywallModal.tsx             買い切り¥480の解放モーダル
assets/sounds/                環境音アセット(呼吸ループ+生活音4種)。README.md参照
scripts/
  generate-sounds.js            呼吸ループ・生活音を生成するプロシージャル音声合成スクリプト
  generate-icons.js             「暖色の光+包み込む弧」マークのアイコン生成スクリプト
```

### ランダム性について

- **声かけの間隔**: 1分30秒〜4分でランダムに次の間隔を決め直す(固定スケジュールにしない)
- **台詞の内容**: 同じトリガー(応援/気遣い)で直前に使った文言は選ばれない
- **生活音**: 45秒〜110秒でランダムに次のタイミングを決め、ため息・伸び・鼻歌・ページめくりからランダムに1つ再生

これらの組み合わせにより「毎回同じにならない」体験を、固定の台本を用意せずに実現している。

### 音楽を止めない

凪・隣と同じく `expo-audio` の `duckOthers` で、音楽アプリを止めずに声・環境音を重ねる。

## 音声について

現在は端末標準のTTS(expo-speech)。呼吸ループ・生活音は `scripts/generate-sounds.js` によるプロシージャル生成(ノイズ整形音、著作権フリー)。品質を上げる場合は隣の音声と同様、高品質TTS APIや実録音への差し替えを検討。

## MVPスコープ

- 実装済み: 4種類の口調 × 声の高さ3段階、時間選択(お試し5分/30分/1時間/2時間)、ランダム間隔での声かけ、呼吸ループ+ランダム生活音、音楽ダッキング、買い切り解放の状態管理とペイウォールUI、ブランドアイコン/スプラッシュ
