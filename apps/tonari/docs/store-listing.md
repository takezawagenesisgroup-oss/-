## App Privacy(データ収集の申告)— 凪との違いに注意

凪は「データ収集なし」だったが、本アプリは**距離・ペース計測のために位置情報を取得する**ため、正確な申告が必要。

**注意(天気連動モード追加により変更): 「第三者への提供・共有」は「しない」ではなくなった。** 天気連動モードをONにしてGPSで開始すると、現在地の緯度経度をOpen-Meteo(外部の気象データAPI)に送信して天気情報を取得する。この機能はユーザーが明示的にONにした場合のみ動作し、送信されるのは緯度経度のみ(アカウント情報・端末識別子等は含まない)。

| 質問項目(Apple) | 回答 |
|---|---|
| 位置情報の収集 | **収集する**(正確な位置情報) |
| 収集した位置情報の利用目的 | アプリの機能(距離・ペース計測、および任意でONにした場合の天気取得)のみ |
| 第三者への提供・共有 | **する**(天気連動モードON時のみ、Open-Meteoに緯度経度を送信) |
| ユーザーに関連付け | しない(位置情報自体はアプリの機能のみに使用し、アカウント等と紐付けない) |
| トラッキング(他社への追跡)への利用 | しない(広告目的の追跡ではなく、天気取得というアプリ機能のための送信) |
| 利用状況データ・識別子・診断データの収集 | 収集しない |

Google Playの「データセーフティ」セクションも同様に、位置情報を「収集する」「アプリ機能に必須」「天気連動時は第三者(気象データプロバイダ)と共有する場合がある」として申告する。プライバシーポリシー本文にもOpen-Meteoへのデータ送信について一文加えることを推奨(`docs/legal/privacy-support.html` を要確認・更新)。
