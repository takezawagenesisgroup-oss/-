# 隣 -Tonari-

ランニング/ウォーキング中に、隣で誰かが気遣いながら話しかけてくれるような音声伴走アプリ。GPSでペース・距離・経過時間を計測し、状況に応じてTTS(端末の音声合成)がリアルタイムで声をかける。Expo (React Native) 製。

競合(MAPLUS+ランニング等)は声優収録の固定音声を1キャラ¥1,080で販売しているのに対し、本アプリはTTSベースで台詞を動的生成することで、声優ライセンス費用ゼロ・買い切り¥480で複数の口調を提供する設計。

## セットアップ

```bash
npm install
npm run web      # ブラウザで動作確認、「デモで体験」ボタンでGPSなしに全機能を試せる
npm run ios      # 要 macOS + Xcode(または凪と同様にEAS Buildでも可)
npm run android
```

## 仕組み

```
App.tsx                    エントリーポイント。口調/声の高さ/目標距離の選択、実行中・終了画面
app/
  theme.ts                 配色トークン(凪とは対照的な、屋外ランを想起させる明るいトーン)
  personas.ts               口調(コーチ/友人/恋人)ごとの台詞バンクとプレースホルダー置換
  useRunSession.ts           GPS(expo-location)またはデモ(シミュレーション)で距離・ペース・
                              経過時間を計測し、トリガー(距離到達・ペース変化・停止検知等)を発火
  useVoiceCompanion.ts        トリガーを受けて台詞を選び、expo-speechで読み上げる。連続発話を
                              防ぐクールダウン付き
  purchases.ts                買い切り解放の状態管理(凪と同じAsyncStorageスタブ実装)
  components/
    PersonaPicker.tsx         口調選択カード(ロック中は🔒)
    PaywallModal.tsx           買い切り¥480の解放モーダル
```

### トリガーの種類

`start` / `distance`(1kmごと) / `time`(5分ごと) / `paceUp` / `paceDown` / `longPause`(45秒停止) / `midpoint` / `nearFinish`(目標の90%) / `finish`。重要な出来事(スタート・ゴール・距離・中間・ラストスパート)は短い間隔でも発話し、雑談寄り(ペース変化・時間経過)はしゃべりすぎないよう間隔を空ける。

### デモモード

実際に歩かなくても、キーフレームベースの疑似ランニングデータ(約75秒で4kmぶんの体験)で全トリガーを一通り確認できる。開発時の動作確認だけでなく、ユーザーが購入前に口調・声の雰囲気を試すプレビュー機能としても使える。

## 音声について

現在は端末標準のTTS(expo-speech / iOS・Androidのシステム音声)を使用しており、声優収録ではない。台詞のテキストは全て自前で用意しているためライセンス費用は発生しない。将来的に音質を上げる場合は、ElevenLabs等の高品質TTS APIや声優収録への切り替えを検討(いずれもコストと引き換えに音質が上がる)。

## 位置情報について

v1はフォアグラウンド(アプリを開いている間)のみの位置情報取得。バックグラウンド(画面ロック中)でのトラッキングはiOSの審査で強い正当化が必要なため、v1では意図的に見送っている。

## MVPスコープ

- 実装済み: GPS/デモでの距離・ペース・経過時間計測、3種類の口調 × 声の高さ3段階、目標距離プリセット、トリガーベースの動的音声、買い切り解放の状態管理とペイウォールUI
- 未実装(v1では意図的に見送り): バックグラウンド位置情報、ブランドアイコン、実際のストア決済連携、ランの履歴保存、高品質TTS/声優音声
