# 隣 -Tonari-

ランニング/ウォーキング中に、隣で誰かが気遣いながら話しかけてくれるような音声伴走アプリ。GPSでペース・距離・経過時間を計測し、状況に応じてTTS(端末の音声合成)がリアルタイムで声をかける。Expo (React Native) 製。

競合(MAPLUS+ランニング等)は声優収録の固定音声を1キャラ¥1,080で販売しているのに対し、本アプリはTTSベースで台詞を動的生成することで、声優ライセンス費用ゼロ・買い切り¥480で複数の口調を提供する設計。

## セットアップ

```bash
npm install
npm run web      # ブラウザで動作確認、「デモで体験」ボタンでGPSなしに全機能を試せる
npm run ios      # 要 macOS + Xcode(または凪と同様にEAS Buildでも可)
npm run android
```

### トリガーの種類

`start` / `distance`(ラン1km・ウォーク0.5kmごと) / `time`(5分ごと) / `paceUp` / `paceDown` / `longPause`(45秒停止) / `midpoint` / `nearFinish`(目標の90%) / `finish`。重要な出来事(スタート・ゴール・距離・中間・ラストスパート)は短い間隔でも発話し、雑談寄り(ペース変化・時間経過)はしゃべりすぎないよう間隔を空ける。同じトリガーで直前に使った台詞は連続して選ばれない。

### ランニング/ウォーキングモード

歩行と走行ではペースの絶対値も変化の出方も異なるため、距離マイルストーンの刻み幅(1km/0.5km)とペース変化の反応閾値をモードごとに変えている(`app/useRunSession.ts` の `MODE_CONFIG`)。デモモードもモードに応じて現実的なペース(ラン平均6分/km、ウォーク平均13分/km)で再生される。

### キャラクター・シチュエーション・天気連動

口調は「人物(コーチ/友人/恋人)」「どうぶつ(犬/猫)」の2カテゴリで選択できる(コーチのみ無料、他は買い切り¥480で解放)。加えてシチュエーション(散歩/通勤・通学/トレーニング/ダイエット/リラックス)を選ぶと、5分ごとの「時間経過」トリガーの約半分がシチュエーション別の一言に差し替わる。さらに「天気連動」をONにしてGPSで開始すると、その場の現在地の気温・天候・昼夜からOpen-Meteo API(無料・APIキー不要)で一言を組み立て、開始直後に一度だけ読み上げる。ネットワークが無い/取得に失敗した場合も通常の声かけは継続する(この開発用サンドボックス環境では外部APIへのアクセスがネットワークポリシーでブロックされているため、実機での動作確認を推奨)。

### デモモード

実際に歩かなくても、キーフレームベースの疑似ランニングデータ(約75秒で体験できる)で全トリガーを一通り確認できる。開発時の動作確認だけでなく、ユーザーが購入前に口調・声の雰囲気を試すプレビュー機能としても使える。

### 音楽を止めない

`expo-audio` の `setAudioModeAsync({ interruptionMode: 'duckOthers' })` により、Spotify等のバックグラウンド音楽を止めずに声を重ねて再生する。iOSはAVAudioSession経由で確実に効くが、Androidはexpo-speechがオーディオフォーカスを自前で取得しないため、OS標準のTTSエンジンの挙動に委ねるベストエフォートである点に注意(詳細はApp.tsxのコメント参照)。

### ラン履歴

走り終えるたびに日時・モード・口調・距離・時間・平均ペースをAsyncStorageに保存し、ホーム画面の「📋 履歴」から一覧確認できる。

## 音声について

現在は端末標準のTTS(expo-speech / iOS・Androidのシステム音声)を使用しており、声優収録ではない。台詞のテキストは全て自前で用意しているためライセンス費用は発生しない。将来的に音質を上げる場合は、ElevenLabs等の高品質TTS APIや声優収録への切り替えを検討(いずれもコストと引き換えに音質が上がる)。

## 位置情報について

v1はフォアグラウンド(アプリを開いている間)のみの位置情報取得。バックグラウンド(画面ロック中)でのトラッキングはiOSの審査で強い正当化が必要なため、v1では意図的に見送っている。
