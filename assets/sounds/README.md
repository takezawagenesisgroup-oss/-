# サウンド素材について

このディレクトリの `.wav` は `scripts/generate-sounds.js` による**プロシージャル生成音**（ノイズ整形 + 減衰トーン合成）です。録音物ではないため著作権上のクリアランスは不要ですが、あくまで開発・動作確認用のプレースホルダーです。

- 雨・波・焚き火・カフェは色付きノイズをフィルタリングして質感を近似したもの
- 風鈴は五音音階のサイン波減衰音をランダムに配置したもの
- ホワイトノイズのみ実運用でもそのまま使える品質です

## リリース前にやること

App Store 申請前に、雨・波・焚き火・カフェ・風鈴は **ロイヤリティフリーまたはライセンス取得済みの実録音**に差し替えることを推奨します（戦略メモのチェックリスト参照）。差し替え手順:

1. 新しい `.wav`（または `.mp3` / `.m4a`）を同名でこのフォルダに置く
2. ループの継ぎ目が聞こえないか実機で確認する
3. `app/sounds.ts` のファイル名・表示名を必要に応じて調整する

再生成したい場合は `node scripts/generate-sounds.js` を実行してください（`assets/sounds/*.wav` を上書きします）。
