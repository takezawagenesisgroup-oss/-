健康ハウス木野温泉 500m規制 距離検証

音更町木野大通東13丁目3番11・4番1（滞在型スパ開発用地、計13,285㎡）と、既存源泉「健康ハウス木野温泉」、および温泉の有無が未確認の「帯広徳洲会病院」との直線距離を、公開座標データを用いて試算した。

対象地 木野大通東13丁目3番11・4番1 基準源泉 健康ハウス木野温泉（木野大通東10丁目6-1） 候補地点 帯広徳洲会病院（木野西通14丁目2-1・未確認） 検証日 2026年9月
主要な発見

試算では、対象地の木野温泉に最も近い「南端」推定点でも約565mとなり、南端・中心・北端のいずれも500m規制ラインの外側という結果になった。仮説にあった「約350〜450m、南側が規制円に抵触」とは約120〜200mの乖離があり、この差自体が実測データでの再確認の必要性を示している（下記「精度に関する重要な注記」参照）。

あわせて、「帯広徳洲会病院にも温泉があるらしい」との情報を受けて座標を試算に加えたところ、中心点で約597m・北端で約605mと、木野温泉より規制ラインまでの余裕が小さい結果になった。ただし同院が温泉法上の源泉を保有しているかは公開情報から確認できておらず、この点は振興局での確認が必要（06章参照）。

北海道内の運用では600mも一応の目安になり得るとの情報を踏まえ600m円も試算したところ、木野温泉側は対象地南端から約34mの区間（全体約312mのうち約11%）が600m円内に入る。病院候補側は対象地の代表線への最接近点が約604.5m（600mまで残り約4.5m）で辛うじて圏外だが、既存の推定誤差（120〜200m規模）を踏まえると実質的に判定不能な際どさであり、600mが適用される場合は入る可能性を否定できない（02章参照）。

05精度に関する重要な注記

この試算を最終判断に使わないでください

国土地理院・Nominatim・Googleマップ等の高精度ジオコーディングにはこの検証環境からアクセスできず、使用できたのは「丁目単位の代表点」座標（国交省「位置参照情報」を元にしたGeolonia住所データ、CC BY 4.0）のみです。

  • 木野温泉の座標＝10丁目という区画全体の代表点であり、実際の掘削井戸の位置ではない
  • 対象地の南端・北端＝隣接丁目（12丁目・14丁目）代表点との中点による補間値であり、3番11・4番1の実際の筆界座標ではない
  • 敷地形状も面積等価の矩形モデルであり、公図上の実形状とは異なる
  • 帯広徳洲会病院＝そもそも温泉法上の源泉を保有しているか自体が未確認（座標は病院所在地の丁目代表点を仮に用いたもの）

仮説（約350〜450m）との120〜200mの乖離は、この推定精度の限界を反映している可能性が高い。音更町の公図・地積測量図と、十勝総合振興局が保有する木野温泉の実掘削位置座標を取得し、同じ手法で再計算することを最優先で推奨する。

06振興局・掘削業者との協議チェックポイント

十勝総合振興局（環境生活課）および温泉ボーリング業者との協議で確認すべき論点。

規制の運用そのものを確認する

  1. 01「北海道温泉保護対策要綱」の現行版を入手し、離隔距離が本当に「原則500m」か、地域・湧出量・温度で基準が変わらないかを確認する。「600mも一応の目安になり得る」との情報の根拠(要綱本文の規定か、運用上の慣行か)も併せて確認する。
  2. 02原則500m以内でも水理地質調査（揚湯試験・水位観測）次第で許可された前例が道内にあるか確認する。
  3. 03距離の起点・終点の定義（既存源泉は井戸位置か建物か／新規は計画井戸位置か敷地境界か）を明確にする。北端掘削戦略はこの定義が前提。
  4. 04測定方法（水平直線距離か道路距離か）と使用する測地系・座標系の指定を確認する。

座標・実測データの確定（最優先）

  1. 05音更町から3番11・4番1の公図・地積測量図（座標付き）を取得する。
  2. 06木野温泉の実際の掘削位置（井戸位置）を、温泉法上の許可申請情報や振興局の温泉台帳から特定する。
  3. 07上記2点を基に土地家屋調査士等による実測を行い、本レポートとの乖離を解消して再計算する。
  4. 08鳳乃舞以外にも、半径500m圏に未把握の源泉井戸がないか温泉台帳で網羅確認する。特に帯広徳洲会病院（木野西通14丁目）が温泉法上の源泉を保有しているかを最優先で確認する（試算では中心点まで約597mと余裕が小さい）。

掘削計画・技術面

  1. 09敷地北端に掘削位置候補を複数案用意し、それぞれ500m規制円外であることを座標で示す申請図面を準備する。
  2. 10圏外であっても近接性から水量・水位への影響評価を求められるか確認する。
  3. 11引湯配管（北端源泉→南側温浴棟）の技術基準・開発行為許可上の扱い・残地区画を横断する場合の地役権要否を確認する。
  4. 12旧河川敷地という地盤・砂礫層の状況を踏まえ、近隣源泉の井戸台帳（深度・温度・成分）を参照した事前見積りを業者に依頼する。

スケジュール・許認可プロセス

  1. 13温泉法に基づく掘削許可の標準処理期間と、利害関係者協議（同法第4条）の有無を確認する。
  2. 14制度上必須でなくても、木野温泉への事前説明が審査上重視されるかを振興局に確認する。
