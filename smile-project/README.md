# スマイルプロジェクト

社内SNS型の「スマイルプロジェクト」UIプロトタイプです。React + TypeScript + Vite + Tailwind CSS で構築しています。

## 機能

- **投稿**: 自分の笑顔の写真（またはスタンプ）を投稿。「スマイル / 挨拶 / エネルギー / 接客品質 / チームワーク」の自己採点チェックリストで30秒程度の自己採点を行い、点数が自動集計されます。
- **承認 → チケット発行**: 投稿に仲間が2名以上承認すると、自動的にドリンクチケットが発行されます（フィード上でワンタップ承認）。
- **ポイント累計**: これまでの投稿で貯めた合計ポイントとチケット獲得数がひと目でわかります。
- **月間スタンプカレンダー**: マイページでは月ごとのカレンダーに「◯月◯日 ◯点」のスタンプが表示され、月間の活動状況が一覧できます。

データはブラウザの localStorage に保存されるデモ用のモックデータです（バックエンドなし）。

## 開発

```bash
npm install
npm run dev      # 開発サーバー起動
npm run build    # 本番ビルド
```
