# スマイルプロジェクト

社内エンゲージメント制度「スマイルプロジェクト」のUIプロトタイプです。React + TypeScript + Vite + Tailwind CSS + shadcn/ui で構築しています。

## デザイン

Instagramのようなシンプルさと楽しげな雰囲気を意識したUIです。背景は白ベースでチャットや余計な装飾を削ぎ落とし、フィードは写真を主役にした縦長カード、投稿・マイページのアバターやストーリー風バブルには紫→ピンク→金のグラデーションリングをあしらってポップな印象を加えています。見出し・数字は「M PLUS Rounded 1c」、アイコンはlucide-reactのアウトラインスタイルで統一。`src/components/ui/` にButton・Card・Badge・Progress・Separatorなどのshadcn/uiプリミティブを実装しています。
（この環境からは `ui.shadcn.com` のコンポーネントレジストリへのネットワークアクセスがブロックされているため、shadcn CLIではなく同等のソースコードを手動で実装しています。）

## 機能

- **投稿**: 自分の笑顔の写真（またはスタンプ）を投稿。「スマイル / 挨拶 / エネルギー / 接客品質 / チームワーク」の自己採点チェックリストで30秒程度の自己採点を行い、Genesisコインが自動集計されます。
- **承認 → Genesisコイン ボーナス**: 投稿に仲間が2名以上承認すると、Genesisコインのボーナスを獲得します（フィード上でワンタップ承認）。
- **日替わりミッション**: 曜日ごとにテーマの異なる接客チャレンジ（月:アイコンタクト・スマイル、火:ファーストボイス・スマイル 等）を表示。挑戦するとボーナスコイン。
- **スマイルプロップス／限定スタンプ**: 投稿時に吹き出しプロップスや季節スタンプを選んで写真に重ねて表示できる。
- **本日のスマイルバディ**: 日付ごとに自動でペアが決まり、一緒に写っている仲間をタグ付けできる。
- **月間スタンプカレンダー**: マイページでは月ごとのカレンダーに「◯月◯日 ◯GC」のスタンプが表示され、月間の活動状況が一覧できる。
- **四季の成長プロジェクト（イベント）**: 年4回（さくらキックオフ／ガーデニング＆空間演出／成果＆ナレッジマルシェ／サンタ・イノベーション）の季節イベントに参加登録・リーダー挙手ができ、それぞれ応じたGenesisコインを獲得。週間コインランキングも同じページに表示。
- **Genesisコイン交換**: 貯めたコインをドリンクやお菓子といった日常のご褒美から、ギフトカード、リゾート宿泊券、豪華食材、特別報奨金、褒賞旅行まで段階的に交換できるカタログ。交換履歴も確認可能。

データはブラウザの localStorage に保存されるデモ用のモックデータです（バックエンドなし）。

## フォルダ構成

Viteプロジェクトのソース一式（`src/`, `public/`, 各種configファイル）をそのままバックアップしています。
`node_modules`・`dist`（ビルド生成物）・`package-lock.json`（`npm install`で再生成可能）は容量削減のため含めていません。

`public/photos/` には実際の従業員の写真（本人の許可を得て投稿デモ用に使用）が入っています。

## 開発

```bash
npm install
npm run dev      # 開発サーバー起動
npm run build    # 本番ビルド
```
