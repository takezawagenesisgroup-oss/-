# スマイルプロジェクト

社内エンゲージメント制度「スマイルプロジェクト」のUIプロトタイプです。React + TypeScript + Vite + Tailwind CSS + shadcn/ui で構築しています。

## デザイン

ダーク基調×ネオンアクセントのスタイリッシュなUIです。背景はほぼ黒（#0c0c0e）、文字はオフホワイトで統一し、インタラクション要素にはホットピンク（#ff3d94）、ポイント表示にはゴールド（#ffcc33）を差し色に使用。アバターやストーリー風バブルには紫→ピンク→金のグラデーションリングをあしらい、フィードは写真を主役にした縦長カードで構成しています。フォントは丸ゴシックの「M PLUS Rounded 1c」から、よりシャープでモダンな「Zen Kaku Gothic New」に変更し、見出し・本文とも統一。アイコンはlucide-reactのアウトラインスタイルです。`src/components/ui/` にButton・Card・Badge・Progress・Separatorなどのshadcn/uiプリミティブを実装しています。
（この環境からは `ui.shadcn.com` のコンポーネントレジストリへのネットワークアクセスがブロックされているため、shadcn CLIではなく同等のソースコードを手動で実装しています。）

## 機能（PDF資料「Smile Project Strategic Realignment」方向性3準拠）

UIは「①イベント報告」「②ポイント（集計・可視化）」「③ポイント交換」の3フェーズ構成です（ジャックポット／抽選要素なし）。ボトムナビは3タブのみで、報告作成はホーム画面右下のFAB（カメラボタン）から行います。

- **①イベント報告**: 「事前行動」「当日の報告」「事後の行動」の3ブロックから、その時にやったこと（例：企画の提案 +100P、気配り・お声掛け +500P、次回への改善提案 +300P 等、全15項目）を選んで写真付きで報告。どのブロックの行動かがひと目で分かるバッジ付きの、Instagramのような縦長フィード表示。詳細な評価基準は別途指示予定のため、現状は視覚面のブラッシュアップを優先。
- **ポイント獲得ルール（いいねベース）**: 投稿には誰でも「いいね」でき、店長・上長を含む3人以上のいいねが集まるとその場でポイント獲得。手動承認は廃止し、フィード上に「あと◯件」の進捗と、店長・上長がいいねした場合のクラウンアイコン表示で、ルールが一目で分かるようにしています。
- **ポイント制度**: 1日60P・月間上限1,200P・年間目安14,400Pを目安に設計。円換算はせず「ポイント」表記で統一。
- **②ポイント（旧イベント＋マイページ統合）**: 自分の保有ポイント・総投稿数、全員の累計ポイントランキング（これまで通り誰でも閲覧可）、月間ポイントカレンダー、最近のポイント履歴を1画面に集約。デモ用に「スタッフ／店長・上長」表示モード切り替えスイッチも搭載。
- **③ポイント交換**: QUOカード／JTB旅行券（各1,000／3,000／5,000円分）に交換できるカタログ。今月の獲得ポイント進捗バー、交換履歴も確認可能。

データはブラウザの localStorage に保存されるデモ用のモックデータです（バックエンドなし）。

## フォルダ構成

Viteプロジェクトのソース一式（`src/`, `public/`, 各種configファイル）をそのままバックアップしています。
`node_modules`・`dist`（ビルド生成物）・`package-lock.json`（`npm install`で再生成可能）は容量削減のため含めていません。

`public/photos/` には実際の従業員の写真（本人の許可を得て投稿デモ用に使用）が入っています。

## 開発

```bash
npm install
npm run dev      # 開発サーバー起動
npm run build    # 本番ビルド
```
